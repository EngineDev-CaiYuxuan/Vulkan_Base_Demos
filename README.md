# Vulkan Base Demos
基于 Vulkan 1.2 的图形 API 练习项目，包含两个独立可运行 Demo，覆盖光栅化渲染管线与计算管线两大核心模块。

## 项目特性
### 公共基础框架
- 完整 Vulkan 实例创建、物理设备特性筛选、逻辑设备与多队列管理
- 交换链管理与窗口大小重绘自动重建
- MSAA 多重采样 + 深度模板缓冲
- 多飞行帧（in-flight frame）同步与命令缓冲复用
- 通用缓冲区工具：暂存缓冲、设备本地缓冲、内存映射、拷贝
- SPIR-V 着色器加载与模块创建

### Demo 1：模型光栅化渲染
- 自定义顶点输入布局，支持 OBJ 模型加载与顶点去重
- 2D 纹理采样 + Mipmap 自动生成 + 各向异性过滤
- 透视投影 + LookAt 相机矩阵
- 深度测试 + 背面剔除 + Alpha 混合
- 索引绘制（DrawIndexed）

### Demo 2：计算管线粒子系统
- 计算管线 + 图形管线双管线架构
- 乒乓 SSBO 双缓冲，读写分离避免数据竞争
- 双队列同步：信号量保证执行顺序 + 内存屏障保证缓存可见性
- 点精灵渲染 + 圆形软粒子 + Alpha 叠加
- 256*256 粒子物理运动模拟

## 技术难点与解决
1. **管线状态污染**：模型与粒子顶点格式、图元拓扑不同，共用管线导致数据错乱。
   解决：为粒子单独创建图形管线，明确顶点输入状态与图元拓扑。
2. **跨队列数据可见性**：计算管线写入SSBO后，图形管线顶点读取到旧数据。
   解决：计算完成后插入内存屏障，保证写入对后续顶点输入阶段可见。
3. **描述符类型不匹配**：缓冲区 usage 与描述符类型不对应导致验证层报错。
   解决：按用途严格区分 UBO / SSBO / 顶点缓冲，描述符类型与 buffer usage 一一对应。

## 构建运行
- 依赖：Vulkan SDK 1.3+、GLFW 3.3+、GLM
- 环境：Visual Studio 2022 / C++17
- 运行：直接编译运行，默认启动粒子系统 Demo
